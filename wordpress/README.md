# Тема WordPress «Новая Формула»

`novaya-formula/` — исходники темы, `novaya-formula.zip` — архив для загрузки в WordPress.

## Установка

1. В админке WordPress: **Внешний вид → Темы → Добавить → Загрузить тему**, выбрать `novaya-formula.zip`, **Установить**, **Активировать**.
2. При первой активации тема сама заполняет сайт текущим содержимым: 4 товара, 5 сегментов «Для кого», 8 условий работы и фото (загружаются в «Медиафайлы»). Если в разделах уже есть записи, они не трогаются.
3. Название сайта «Новая Формула» и описание «моющие средства от производителя» ставятся, только если там стояли стандартные значения WordPress. Поменять: **Настройки → Общие**.

Плагины не нужны. Требуется WordPress 6.3+ и PHP 7.4+.

## Где что редактировать

| Что на сайте | Где в админке |
|---|---|
| Первый экран, «Дилерам», заголовки разделов, «Скоро в линейке», широкое фото, контакты, подвал, описание для поисковиков | **Настройки сайта** |
| Карточки товаров и быстрые ссылки на первом экране | **Продукция** |
| Прачечные, гостиницы, химчистки, дом, магазины | **Для кого** |
| Строки «Условий работы» | **Условия работы** |
| Логотип (вместо надписи «логотип в разработке») и значок вкладки | **Внешний вид → Настроить → Свойства сайта** |

- Порядок товаров, сегментов и условий — число в блоке «Порядок на сайте» справа на странице записи: меньше — выше.
- В пунктах (преимущества товара, сегмента) первое предложение до точки само выделяется жирным. В пунктах первого экрана жирным выделяется текст до двоеточия.
- Отдушки и фасовка — через запятую с пробелом: `0,5 л, канистра 5 л`.
- Товар без фото показывается с заглушкой «Этикетка в разработке».
- «Записи» и «Комментарии» на этом сайте не используются и скрыты из меню.

## Структура

```
novaya-formula/
├── assets/            css (base + blocks, как в site/), js, fonts, icons, images, admin
│   └── css/wp.css     только для WordPress: логотип-картинка и отступ под админ-панель
├── inc/               helpers, setup, enqueue, post-types, meta-boxes, options, demo-content
├── template-parts/    hero, products, photo-band, audience, terms, contact
├── front-page.php, header.php, footer.php, index.php
├── functions.php
└── style.css
```

Стили и скрипты в `assets/` — копия `site/css` и `site/js`. Если меняется вёрстка в `site/`, их нужно скопировать в тему и пересобрать архив.
